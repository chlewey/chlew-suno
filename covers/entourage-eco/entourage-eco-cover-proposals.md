# Entourage covers -- illustrated set

This is the active set read by `gen_covers.py`. The earlier photorealistic set is kept, unused, in `entourage-eco-cover-proposals-photorealistic.md`.

### How to use

- **Every prompt ends with the house-style paragraph.** It is repeated in full so each
  prompt can be pasted on its own.
- **Characters come from `characters.yaml`.** The short descriptions in the prompts are
  condensed from it; if a character's look changes, change it there first.
- **Thomas is never shown face-on**: absent, in silhouette, or from behind/background --
  black hair, a well-groomed gray-and-black beard, light brown skin, 5'11", a polo shirt
  or a custom-tailored suit.
- **One place, one moment.** No split frames, composites or "one view that is two places":
  generators fill the gap with impossible geometry. Carry a second place with a prop instead
  (winter coats carried into the heat), and keep every object where it physically would be.
- **If the figures come out painted** instead of inked (the style collapses into overall
  watercolour), move the house-style paragraph to the start of the prompt and repeat
  "ink outlines, flat colour" for the characters.
- **No readable text** in any image: handwriting, screens and signs are suggested, never legible.
- Each cover's colour follows its own scene; the shared ink-and-gouache style ties the set together.

### House style

> Comic-book illustration. Characters drawn in clear-line style: clean ink outlines of even weight, flat cel colours with at most one shadow tone, no hatching, no gradients on skin or clothing. Backgrounds painted in gouache and watercolour: soft, atmospheric, no outlines, visible brush texture, naturalistic light, so the crisp figures stand out against a painterly world. No text, lettering, signage or speech balloons; no panel borders. Square 1:1 aspect ratio.
